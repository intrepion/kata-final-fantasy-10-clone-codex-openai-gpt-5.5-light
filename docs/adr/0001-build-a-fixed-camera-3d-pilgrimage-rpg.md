# Build A Fixed-Camera 3D Pilgrimage RPG

We will build an original browser RPG around fixed-camera 3D pilgrimage scenes rather than an open world, flat menu prototype, or free-camera action RPG. This best preserves the authored, cinematic journey feel while keeping the first browser-playable slices small enough to verify end to end.

**Considered Options**

- Free-camera third-person exploration
- 2D or 2.5D JRPG adaptation
- Menu-only combat prototype
